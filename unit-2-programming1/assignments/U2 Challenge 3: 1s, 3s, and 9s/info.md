Take a number from a user, and output how many 1s, 3s, and 9s would fit in that number.

Examples:
- User inputs "14", the program would output, "1 nine, 1 three, and 2 ones".
- User inputs "21", the program would output, "2 nines, 1 three, and 0 ones".

For this challenge, you cannot use "import math".

HINT: Looking up how % (modulus) works in Python might help solve this one!
