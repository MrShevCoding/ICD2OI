Take two numbers from a user, and output the change as a percent from the first number to the second.

For example, for the inputs "800" and "600", the program would output "25% decrease". For the inputs "100" and "950", the program would output "850% increase".

As with most of these challenges, you may need to use the internet to learn how to do this.
My absolute favorite resource for learning coding things is w3schools. They teach you about programming tools, give examples, and let you experiment live on their site. Give it a look if you are stuck.
