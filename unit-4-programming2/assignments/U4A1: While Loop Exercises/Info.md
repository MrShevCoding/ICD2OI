1. Change the program Math Quiz.py so that it:
Keeps track of their score and lives: The user gets 50 points for every right answer. The user loses a life for every wrong answer. (Hint: increment and decrement statements)

Let the user play the game repeatedly until he/she has missed 3 problems. 
(Hint: while loop)

Prints the final score after the user has lost.

2. Write a program that has a number from 1–100 randomly chosen in the code –
    the magic number—and makes the user keep guessing until they get it right,
    but gives the user the following helpful feedback after every wrong guess:

If the user’s guess is lower than the magic number, the program should
print “Too low! Guess again” and have the user guess again.

If the user’s guess is higher than the magic number, the program should
print “Too high! Guess again” and have the user guess again.

The program should print “Yes! You got it!” if the number is guessed
correctly, and the program should stop.

Extra Challenge: Give the user only 5 guesses before the program tells
them that they lost and restarts.
