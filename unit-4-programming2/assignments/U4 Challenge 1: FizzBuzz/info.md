Go through every integer from 1 to 100. If the integer is divisible by 3, print "Fizz". If the integer is divisible by 5, print "Buzz". If the integer is divisible by both 3 and 5, print "FizzBuzz". If it is divisible by neither, just print the number.

So output should be: "1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz, etc..."

Only restriction: your program should be under 14 lines of code.

This is actually a classic interview question, that you may one day have to do if you apply for a programming job!
