# Loops Project

**Problem 1:**  **Number Reduction Game**

Rules of the number reduction game:

* To start the game, Player 1 picks any whole number greater than 2\.  
* The players take turns reducing the number by either:  
  * Subtracting 1 from the number his/her opponent just wrote, OR  
  * Halving the number his/her opponent just wrote, **rounding down** if necessary.  
* The first player to write a 0 wins.

**Task**:  Write a Python program that lets two players play this game.

Requirements:

1. Ask Player 1 to enter the starting number.

2. Use a while-loop to allow the players to take turns reducing the number until someone wins.  
     
3. Restrict players so they can only choose valid choices for the next number (on an invalid choice, either ask the user to try again, or just call them a cheater and quit the program).

4. Each time a player enters a valid number, inform the other player what his/her choices are and ask him/her to enter the next number.

5. Declare the winner when someone enters 0\.

Example session:

Player 1, enter a number greater than 1:   **16**

Player 2, your choices are 15 or 8:   **15**

Player 1, your choices are 14 or 7:   **7**

Player 2, your choices are 6 or 3:   **3**

Player 1, your choices are 2 or 1:   **2**

Player 2, your only choice is 1:   **1**

Player 1, your only choice is 0, so you win\!

\*\*\*Player 1 wins\*\*\*

**Exceed Expectations:** Have an additional option to play against a computer.  To receive the full marks, the computer must use some kind of intelligent strategy and not just choose randomly.

Here are the requirements:

* User friendliness:  
  * All output should be formatted in an easy to read way (use space, consistent capitalization/punctuation, etc)  
  * The program should give the user the option to print out the rules of the game.  
  * All input statements should have clear directions, so that it is clear what the user is supposed to enter.  
  * When the game ends, the program should print a summary of the results, depending on what stopped the game (e.g. a certain score was reached, or the user quit.)

* Non-lameness:  
  * Put some flair into it. Try to show me something you think I haven’t seen before.  
  * Make the output look nice and pay attention to detail (spacing, formatting, etc).  
  * Make it engaging, so that the user has to think carefully about what to do at each step.
