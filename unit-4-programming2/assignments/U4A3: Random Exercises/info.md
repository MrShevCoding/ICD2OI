# Random Exercises

1\. Write a program that simulates a coin game. The program should do the following:

* Ask the user how many times they would like to flip a coin.  
* Randomly choose “Heads” or “Tails” each flip  
* Print out what face was chosen  
* On a “Heads”, increase their score by 1  
* Print their total score after the flipping is done

2\. Write a password generator program. The program should:

* Ask the user how many words the password should be made of  
* How many digits the password should include  
* Generate a password based on those inputs. The password should:  
  * Start with a random set of words, equal to the number the user input  
  * End with a random set of digits, equal to the the number the user input  
    

For example, if the user input “2” and “5”, the password might be “frenchguppy42337”
