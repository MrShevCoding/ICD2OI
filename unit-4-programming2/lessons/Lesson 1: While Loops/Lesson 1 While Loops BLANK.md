## **Increment Statements**

Increment statements are a common programming technique used to increase the value of a variable.

| Line | x var. value | y var. value | Explanation |
| :---- | :---- | :---- | :---- |
| 1 | 10 | N/A | Only x was given |
| 2 | 10 | 5 | Both have been stated |
| 3 | 12 | 5 | X had changed to 12 |
| 4 | 12 | 8 | Y was overwritten Python evaluates RS (y \+ 3 \== 8\) Then assigns 8 to Y |

## **Common Examples**

**Increment Statements**

| Collecting a coin in a game (coins \+= 1\)  Timers ( Time \+= 1 every sec) Online shopping carts (Adding an item to your cart) |
| :---- |

**Decrement Statements** (Similar to an increment, but for decreasing a variable e.g. x \= x \- 1\)

| Health in video games (Health \-= Damage) Battery in devices  Password attempts (You do a few then it locks you out) |
| :---- |
