Using loops and turtle (or tkinter), create this shape in Python!

If you choose to use turtle, you will likely need to use this new turtle function:

turtle.goto(x,y)
#moves the pen to coordinate x,y on the canvas

NOTE: There are only straight lines used to create this image. No curves!
