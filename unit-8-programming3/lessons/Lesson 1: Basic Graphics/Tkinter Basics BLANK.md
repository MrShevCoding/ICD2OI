Tkinter Basics  
---

Briefly explain how each of these concepts/functions work in tkinter. Feel free to add new concepts or functions that you discover.

You can use this sheet as a reference for future projects.

Screen coordinates: 

canvas(): This sets up the drawing space. Set the width, height and bg colour

update(): Useful when doing animation \- ignore for now

Parameters: Options that go in a functions bracket, usually separated by commas. They change how the function works.

create\_rectangle(): Creates a rectangle shape given two coordinates for top left and bottom right corners of rectangle (x1,y1,x2,y2)

* Possible parameters: Fill \- fill rectangle with a given colour, Outline \- changes the outline colour

create\_text(): Creates text centered around desired coordinates

* Possible parameters:  Font \- Change the front to your liking, Fill \- Fill text with a colour

create\_line(): Makes a line between set given coordinates

* Possible parameters: Fill \- Coulour of the line, Width \- how wide it will be, cenetered on the line between the 2 coordinates, smooth \= true to smooth out a line

create\_polygon(): Makes a polygon connecting all the point you input in order

* Possible parameters: Fill- Colour, smooth \= true to smooth out the whole polygon

create\_oval(): Makes oval within a rectangle made in 2 coordinates 

* Possible parameters: Fill \- Colour

create\_arc(): Makes an arc within a circle

* Possible parameters: FIll- Colour, start \= what angle in the circle would you start, extent \= how far by what angle do you wish to fill
