# Animation Lesson

1. Warmup \- Anchors  
   1. Move the Bear Face to the center of the screen WITHOUT directly changing the x and y coordinate numbers in the tkinter functions.  
   2. As a hint, check out assignment U8A2 with the pumpkins and the anchor points.

2. [Flipbook Animation Video](https://www.youtube.com/watch?v=JVzf9rtgf9Y) \- how animation works  
     
3. Using *1 Simple Ball Animation.py* as a starter, make a flying brick.  
   1. It should be a rectangle that is taller than it is wide.  
   2. The brick should move from the bottom of the screen to the top.

4. Using *2 Two Object Animation.py* as a starter, make the balls animate not at the same time.   
   1. First, the red ball should move left to right.  
   2. Then the blue ball should move from top to bottom.  
   3. Reduce the length of the red ball animation so there isn’t a large pause between the two animations

5. Using your solution to challenge 2 as a starter, make the blue ball bounce off the ground.   
   1. Look at *3 Changing Direction.py* for clues on how to make this work.
