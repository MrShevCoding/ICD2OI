Halloween Scene Exercise

Given the starter code, animate the Halloween scene in the following way:
The tree should move slowly to the left
The pumpkin should bounce up and down in place at the same time as the tree movement
The tree and pumpkin should still be on the screen at the end of the animation (how can we prevent the s.delete() on the last frame of the animation?)

BONUS 1: Make the pumpkin move to the right quickly as it bounces, and exits screen right.

BONUS 2: Create an object (moon, bat, etc) that flies in from offscreen, AFTER the pumpkin leaves the scene and the tree stops moving.
